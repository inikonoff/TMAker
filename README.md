# TMA Builder

Визуальный конструктор Telegram Mini App для личного использования: рисуете экраны, связываете их переходами,
проходите сценарий как в живом приложении, подключаете данные и бота, получаете готовую папку для VS Code
и языковой модели.

- **Один проект — один JSON.** Превью, экспорт и ИИ производны от него.
- **Статика.** Работает на GitHub Pages без сервера; проект и картинки хранятся в IndexedDB браузера.
- **Русский интерфейс по умолчанию**, английский — в меню «⋯ → Язык».

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте http://localhost:5173.

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер Vite |
| `npm run typecheck` | проверка типов (strict) |
| `npm test` | тесты логики (vitest) |
| `npm run build` | статическая сборка в `dist/` |

## Что умеет

**Холст.** Панорама и зум одной CSS-трансформацией (колесо мыши и щипок — масштаб к курсору 0,25–3, правая кнопка мыши — двигать холст). Перетаскивание с пружинным следованием и посадкой 340 мс, магнитные направляющие как в Canva
(края и центры соседей и экрана), сетка 4 px. Ctrl или кнопка-магнит отключают привязку. Изменение размера за 8 ручек
(Shift — пропорции), рамка выбора, перенос элементов между экранами, группы, слои, выравнивание и распределение,
«Упорядочить» (повторное нажатие отменяет). История на 100 шагов, автосохранение.

**Элементы.** Кнопка, текст, картинка, фигуры (прямоугольник, эллипс, треугольник, звезда, многоугольник), линии и стрелки
с концами, привязанными к элементам, блок, карточка, поле ввода, список, вкладки, навигация, разделитель, бейдж,
переключатель, флажок, ползунок, а также MainButton, BackButton и шапка Telegram. Рамки: сплошная, пунктир, точки,
двойная. Картинка на кнопке и любом блоке (заполнить / вписать / иконка) — из файла или Ctrl+V.

**Запуск.** Экран устройства по центру, клики по элементам, переходы slide (4 стороны), fade, expand, none.
«Назад» проигрывает тот же переход в обратную сторону. Свайп «за пальцем» с порогом 25% или по скорости.
Подсветка кликабельных зон, путь, карта связей, цвета Telegram (светлая / тёмная). Уважается `prefers-reduced-motion`.

**Темы.** Светлая и тёмная; у тёмной ползунок серого от почти чёрного до светло-серого, меняется плавно на холсте
и в превью. Тема редактора и тема приложения независимы.

**Данные и бот.** Таблицы, поля, типы, связи; привязка элементов (список, форма добавления, одно значение);
песочница данных в режиме «Запустить» переживает перезагрузку. Команды бота. Токены в проект не попадают.

**Экспорт.** Папка (Chrome/Edge, File System Access API) или ZIP: `project.json`, `PROMPT.md`, `AGENTS.md`, `CLAUDE.md`,
`screens/*.png`, картинки. По желанию — заготовка: `app/` (Vite + React + TS + Telegram WebApp SDK) и `server/`
(Hono API + grammY + Drizzle на SQLite или Postgres, проверка `initData`, миграции, Dockerfile, README по деплою).
Ссылка на проект `#docz=` (сжатый JSON в адресе).

**ИИ (Groq).** Собрать экран по описанию, предложить схему данных, переписать тексты. Ответ — фиксированный JSON,
модель не задаёт координаты (раскладку делает конструктор). Результат — черновик: «Оставить» или «Отменить».
Ключ хранится только в браузере. Если Groq не пускает запросы из браузера (CORS), разверните прокси из
[`proxy/groq-worker.js`](proxy/groq-worker.js) на Cloudflare Workers и укажите его адрес в Base URL.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Z / Ctrl+Shift+Z, Ctrl+Y | Отменить / вернуть |
| Delete / Backspace | Удалить выделенное |
| Ctrl+D | Дублировать |
| Ctrl+C / Ctrl+V | Копировать / вставить элементы (Ctrl+V с картинкой — вставить картинку) |
| Ctrl+A | Выделить всё на экране |
| Ctrl+G / Ctrl+Shift+G | Сгруппировать / разгруппировать |
| ] / [ | Выше / ниже по слоям (с Ctrl — на передний / задний план) |
| Стрелки (Shift — по 10) | Сдвинуть на 1 px |
| Esc | Снять выделение / выйти из запуска |
| Правая кнопка мыши + перетаскивание | Двигать холст (также пробел + левая кнопка, средняя кнопка) |
| Колесо мыши | Масштаб к курсору |
| Shift + колесо | Двигать холст (удобно на трекпаде) |
| Ctrl при перетаскивании | Без привязки |
| Shift при изменении размера | Сохранять пропорции |
| Shift+1 | Показать все экраны |
| Ctrl+0 | Масштаб 100% |
| Shift+T | Упорядочить экран |
| P | Запустить / остановить |

На телефоне: один палец по пустому месту — двигать холст, два — масштаб; привязка выключается кнопкой-магнитом.

## Устройство кода

```
src/
  lib/         чистая логика без React, покрыта тестами
    model.ts       типы проекта (версия, экраны, элементы, данные, бот)
    validate.ts    валидатор и миграции: любой вход проходит через parseProject
    geometry.ts    прямоугольники, зум к курсору, изменение размера
    snap.ts        направляющие, магнит (1 - d)^2.2, сетка
    history.ts     история снимками, слияние правок поля за 800 мс
    ops.ts         операции над документом (экраны, элементы, слои, стрелки)
    arrange.ts     выравнивание, распределение, Tidy
    transitions.ts позы переходов вперёд/назад, свайп
    color.ts       цвета, токены темы, darkLevel, themeParams Telegram
    ai.ts          промпты и разбор ответов ИИ
    export/        PROMPT/AGENTS, SQL и Drizzle, шаблоны заготовки, сборка файлов
    i18n.ts        переводы (ключ — русская строка), i18n.en.ts — английский
  store/       Zustand: редактор, перетаскивание, IndexedDB, картинки
  components/  тонкий UI: холст, панели, запуск, окна экспорта / данных / ИИ
proxy/         прокси для Groq на Cloudflare Workers
```

Техника холста и анимаций вдохновлена разбором [lnkiai/m3e-canvas](https://github.com/lnkiai/m3e-canvas) (MIT);
код написан заново.

## Деплой на GitHub Pages

Workflow `.github/workflows/pages.yml` на каждый push прогоняет typecheck, тесты и сборку, а из ветки по умолчанию
ещё и публикует `dist/`. В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
С источником «Deploy from a branch» GitHub отдаёт исходники без сборки — будет пустая страница (с подсказкой через 4 с). Сборка использует относительный `base`,
поэтому работает из любой подпапки.

Публикуйте сборку только для себя: ключ ИИ вводится в браузере и хранится локально, но инструмент рассчитан на личное
использование.
